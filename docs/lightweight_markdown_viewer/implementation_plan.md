# 実装計画: 超軽量・高機能 Markdown Viewer (showmd)

このドキュメントでは、ユーザーの要求（超軽量・爆速起動・テーブル等の構文フルサポート・自動更新・美しい表示）を満たすための設計方針と実装計画を提案します。

---

## 📌 技術選定とアーキテクチャ

「超軽量（EXEサイズを最小に、起動を最速に）」と「テーブル等の構文フルサポート・完璧な表示」を両立するため、以下の構成を提案します。

### 採用技術
1. **GUIコンテナ**: `pywebview`
   - **理由**: Windows標準の **Microsoft Edge WebView2 (Chromium)** を利用します。アプリ本体にブラウザエンジン（Chromium等）を同梱する必要がないため、PyInstallerで固めた際のEXEサイズを **約10MB〜15MB程度** に抑えられます。
   - ウィンドウの最大化・最小化・リサイズ、クローズ時のプロセス終了など、Windows標準のウィンドウ挙動を完全サポートします。
2. **Markdownパーサー**: `markdown` (Pure Python) + `pymdown-extensions` (または標準の `tables` 拡張)
   - **理由**: Pure Pythonで書かれており、追加のC言語拡張やバイナリ依存がないため非常に軽量です。テーブル構文やコードブロック、Fenced Codeなどを完璧にサポートします。
3. **HTML/CSS レンダリング**:
   - WebView2上で動作するため、モダンなCSS（レスポンシブデザイン、美しいフォント、スタイリッシュなテーブル、ダークモード対応など）を完璧に適用できます。
4. **ファイル監視 (ホットリロード)**:
   - バックグラウンドスレッドで対象ファイルの最終更新日時 (`os.path.getmtime`) を定期的に（例：0.5秒間隔）ポーリング監視します。
   - ファイルの変更を検知すると、バックグラウンドでMarkdownをHTMLに再変換し、WebViewにロード（ホットリロード）します。追加の重いライブラリ（`watchdog`など）を使わず、標準ライブラリのみで軽量に実装します。

## 🛠 実装詳細

### 1. UIデザイン & 表示のこだわり
- メニューバーやツールバーは一切配置せず、スクロールバーのある表示エリアのみを表示します。
- CSSにはモダンなスタイルシート（例: GitHub風の美しいMarkdownテーマ）をインラインで組み込み、テーブル（セル境界線、ヘッダー背景色、パディング）、コードブロック、フォント（Windows標準の `Segoe UI` や `Yu Gothic` など）を完璧にレンダリングします。
- リンク (`<a href="...">`) をクリックした際は、アプリ内ではなく、Windowsの既定のブラウザ（Chrome, Edge等）でリンクが開くようにフックします。

### 2. コマンドライン引数とファイル監視
- `showmd.exe <filepath.md>` で起動。
- 起動時に指定されたファイルの存在を確認し、存在しない場合はエラーメッセージを表示して終了します。
- 起動後、別スレッドでファイル監視ループを開始し、更新を検知したら `webview.windows[0].load_html(new_html)` を実行します。

## 🔬 検証計画

### 1. 自動テスト・動作確認
- テーブル、リスト（ネスト）、太字、イタリック、コードブロック、インラインコード、リンク、画像など、主要なMarkdown要素を含むテスト用Markdownファイル (`test.md`) を作成し、WebView2で完璧に表示されるか確認します。
- ウィンドウの最大化・最小化・ドラッグによるサイズ変更がスムーズに行えることを確認します。

### 2. ファイル変更監視（ホットリロード）の確認
- `test.md` を開いた状態で、テキストエディタでファイルを変更・保存し、`showmd` の表示が即座に（1秒未満で）更新されることを確認します。

### 3. EXE化と軽量性の確認
- `PyInstaller` でパッケージングし、生成された `showmd.exe` のファイルサイズが15MB以下であることを確認します。
- 起動速度が1秒未満であることを確認します。
